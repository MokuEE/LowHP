# HP Watch

完全在瀏覽器本機執行的遊戲 HP 即時警報工具，不會上傳或儲存擷取畫面。

## 啟動

在此資料夾執行：

```powershell
python -m http.server 4173
```

然後開啟 `http://localhost:4173`。建議使用最新版 Chrome 或 Edge。

1. 點「開始擷取畫面」並選擇遊戲視窗或整個螢幕。
2. 在預覽畫面拖曳框選紅色 HP 條內部。
3. 點「播放測試音」解除瀏覽器自動播放限制，再啟動監控。

預覽操作：滑鼠滾輪可縮放（以游標位置為中心），按住中鍵拖曳可平移畫面，左鍵拖曳用來框選 HP 偵測區域；「重設視角」可回到 100%。

警報門檻、提醒開關、間隔、音量與 HP 框選位置會自動儲存在瀏覽器本機儲存空間，下次開啟時自動還原；資料不會上傳。

> 若遊戲視窗在被其他視窗遮住或最小化後停止更新，請改為分享「整個螢幕」。
